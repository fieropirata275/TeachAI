# TeachAI
Open-source AI tutor that teaches any subject using a live interactive whiteboard, voice, vision and local LLMs through LM Studio or DeepSeek.

USAGE

python paint_professor.py --install first to install all dependencies without hassle.

python paint_professor.py on the same directory to initiate your own Teacher, it uses your own GPU and a model selected by us to work just fine for the task, although it allows to input a Deepseek API key if you want even more AI inteligence, but the already implemented security and safeguards make the AI work and answer just fine, although it may seem a little bit dumb or dry on the explanations, we are working for it to work better
